# 기타 도감

코드 운지 사전, 키별 코드, 스케일 도감, 리프 만들기가 들어 있는 기타 연습 웹 앱이에요.
휴대폰 홈 화면에 아이콘으로 설치할 수 있고, 한 번 열면 인터넷이 없어도 켜져요.

## 1. 처음 한 번: GitHub Pages로 올리기 (무료)

1. github.com 에 가입하고 로그인해요.
2. 오른쪽 위 **+** → **New repository** → 이름을 `guitar-dogam`으로 정하고 **Public**으로 만들어요.
3. 저장소 화면에서 **Add file → Upload files**를 누르고, 이 폴더 안의 파일과 `js` 폴더를 전부 끌어다 놓은 뒤 **Commit changes**를 눌러요.
4. **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 정하고 **Save**를 눌러요.
5. 1~2분 뒤 `https://내아이디.github.io/guitar-dogam/` 주소로 열려요. 이 주소를 친구들에게 보내면 돼요.

## 2. 휴대폰에 앱으로 설치하기

- **안드로이드(크롬)**: 주소를 열고 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**
- **아이폰(사파리)**: 공유 버튼 → **홈 화면에 추가**

## 3. 기능을 바꾸거나 추가하기

파일을 고쳐서 GitHub에 다시 올리면 1~2분 뒤 사이트에 반영되고,
설치된 앱도 인터넷이 연결된 상태로 다시 열면 새 버전으로 바뀌어요. (따로 버전 번호를 올릴 필요 없어요.)

**고치는 방법**
- GitHub 저장소에서 파일을 누르고 연필(✏️) 아이콘으로 바로 고친 뒤 **Commit changes**
- 또는 Claude에게 “guitar-dogam 저장소에 ○○ 기능 추가해줘”라고 부탁하고, 저장소를 연결해 주면 Claude가 고쳐서 올려 줄 수 있어요.

**어떤 파일을 고치면 되는지**

| 파일 | 내용 |
|---|---|
| `index.html` | 화면에 보이는 글자, 버튼, 탭 구성 |
| `style.css` | 색, 글꼴, 크기 (맨 위 `:root`의 색 변수만 바꿔도 전체 색이 바뀌어요) |
| `js/chords.js` | 코드 종류 목록(`QS`), 대표 운지(`OPEN`, `SH`), 운지 계산 규칙 |
| `js/key.js` | 키별 코드 탭, 주법별 추천 코드(`STY`) |
| `js/dictionary.js` | 코드 사전 탭 |
| `js/scales.js` | 스케일 도감(`SCL`에 스케일을 추가할 수 있어요) |
| `js/riff.js` | 리프 만들기, 스트로크 패턴(`STRUM`), 주법 패턴(`PAT`) |
| `js/sound.js` | 기타 소리, 리버브 |
| `js/main.js` | 탭 전환 |
| `sw.js` | 오프라인 지원 (보통 고칠 필요 없어요) |
| `manifest.webmanifest`, `icon-*.png` | 앱 이름과 아이콘 |

**예시: 스트로크 패턴 하나 추가하기**
`js/riff.js`의 `STRUM` 목록에 한 줄을 더하고, `index.html`의 스트로크 패턴 선택 메뉴(`id="rfsp"`)에 같은 순서로 `<option>`을 하나 추가하면 돼요.
패턴 글자: `D` = 다운(↓), `U` = 업(↑), `.` = 쉼.

## 주의

- 파일을 컴퓨터에서 더블클릭해서 열면 앱 설치와 오프라인 기능은 작동하지 않아요. 꼭 https 주소로 올려서 써요.
- 녹음 파일로 만든 기타 소리는 그 기기 화면에서만 쓰이고, 앱을 다시 열면 다시 올려야 해요.
